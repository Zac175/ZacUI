# ZacUI

A complete, fully customizable interface for WoW Classic Era, TBC Anniversary and WoW Forever: unit frames,
nameplates, action bars, bags, damage and threat meter, class HUDs, raid mods, raid tools, maps and more.

**Download:** [ZacUI on CurseForge](https://www.curseforge.com/wow/addons/zacui) (or the CurseForge app).
Each `Zacui*` folder goes in `Interface\AddOns`. Type `/zacui` in game to open the settings.

`/zacui flavor` lists what works differently on the game version you're playing.
